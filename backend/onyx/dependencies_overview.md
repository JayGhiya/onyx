# Dependencies Overview

> **Source of truth** for all third-party dependencies used in this Python/pip project.
> Add a new entry here whenever a new package is introduced.

## Format

Each entry follows the template below:

```
### <package-name>
- **Version / pin**: (e.g. `>=1.2,<2.0`)
- **Purpose**: One-sentence description of what the package does.
- **Usage**: Where / how it is used in the codebase.
- **Requirement file(s)**: (e.g. `backend/requirements/combined.txt`)
```
